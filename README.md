בפרויקט זה בחרתי בגישת הנדסה רב-שכבתית (Multi-layered Architecture), המשלבת לוגיקה עסקית קשיחה יחד עם יכולות ההסקה של בינה מלאכותית. מטרת העל הייתה ליצור מערכת המלצות שהיא לא רק "חכמה", אלא קודם כל אמינה, מדויקת וחסכונית במשאבים.
התהליך מתבצע בשלושה שלבים מרכזיים:
אימות וסינון דטרמיניסטי (The Guard): לפני הכל, המערכת מבצעת וולידציה קפדנית על סוגי הנתונים (Types) ותקינות הקלט. בשלב זה מתבצע סינון ראשוני אגרסיבי שמסיר מהמאגר פריטים שאינם עומדים בתנאי הסף (כמו תקציב או צבעים אסורים). זה מבטיח שה-AI יעבוד רק עם נתונים רלוונטיים, מה שחוסך זמן וטוקנים.
דירוג אינטליגנטי (The Brain): המידע המזוקק עובר ל-AI (דרך Groq) באמצעות פרומפט דינמי שנבנה בזמן אמת לפי פרופיל המשתמש. ה-AI מבצע את הדירוג הסגנוני ומייצר לכל פריט נימוק מפורט ומותאם אישית (Reasoning).
בקרה ואימות (The Safety Net): מתוך הבנה שאי אפשר לסמוך על AI בעיניים עצומות, המערכת כוללת שכבת בדיקה נוספת לאחר קבלת התוצאות. המערכת מוודאת שהפריטים שהוחזרו אכן קיימים במאגר המקורי, עומדים במגבלות שהוגדרו ושהם אכן הדירוג האופטימלי עבור הלקוח.

הוראות הרצה:
ודאי שמותקן אצלך Node.js (גרסה 18 ומעלה).
בצעי העתקה של הפרויקט אצלך במחשב- clone 
פתחי טרמינל בתיקיית השורש של הפרויקט והריצי את הפקודה: npm install.
צרי קובץ חדש בשם .env בתיקיית השורש של הפרויקט.
בתוך קובץ ה-.env הוסיפי את השורה: GROQ_API_KEY=your_key_here (החליפי את your_key_here במפתח האישי שלך מ-Groq).
להפעלת השרת הריצי את הפקודה: npm start.
השרת יתחיל לרוץ בכתובת: http://localhost:3000.
להרצת הבדיקות האוטומטיות הריצי את הפקודה: npm test.
ניתן לבדוק את ה-API על ידי שליחת בקשת POST לכתובת http://localhost:3000/recommendations עם גוף JSON המכיל את פרופיל המשתמשת.
החלטות עיצוב מרכזיות:
בניתי מנגנון דירוג שמבוסס על משקלים. במידה וה-AI לא זמין, המערכת משתמשת בנוסחה מקומית: Style Match מקבל את העדיפות הכי גבוהה (פי 3), לאחר מכן Color Match (פי 2), ובונוס נוסף על התאמה ל-Occasion. אם יש תיקו בניקוד, המערכת תעדיף את המוצר הזול יותר.
אם אין אף מוצר בטווח המחירים של המשתמשת, המערכת מחזירה שגיאה ברורה (400) ולא ממשיכה ל-AI. אם ה-AI "הוזה" וממציא מוצר שלא קיים, ה-Validation שלי פוסל את התשובה ועובר אוטומטית לגיבוי המקומי (Fallback).
 בחרתי ב-Node.js כי היא מצוינת לעבודה אסינכרונית עם APIs וטיפול ב-JSON. השתמשתי ב-Groq SDK כדי לקבל תשובות מהירות מאוד מה-AI, מה שמשפר את חוויית המשתמש.
 השתמשתי ב: cursor וב: claude בעיקר בשביל לבנות שלד ראשוני לפרויקט לייצר פרומפט איכותי מלא שמקיף לי את כל הבדיקות וירידה לכל הדקויות. 
 במהלך העבודה על הפרויקט שעבדתי עם cursor עברתי בין המצבים לפעים מצב ASK ולפעמים agent ומייד לאחר שהכנסתי את המפתח וראינו שזה עובד הוא רצה להמשיך יש לקונטרולר
 אבל לי היה מאד חשוב לבצע שוב בדיקה, פעולה אחת שכל הפל יכנס אליה ויבדק והוא טען שלא צריך כי בד"כ הבינה מאד מדויקת אבל לאחר שהסברתי ופרטתי ממש למה זה חשבו והבאתי לו דוגמאות הוא הסכים 
 שזה כן חכם והמשכנו הלאה
 ועוד משהו שלקחתי את הקובץ json של הפרודוקטים והפכתי אותו למערך של מלא אובייקטים כך שהעבודה איתו תיהיה יותר נוחה
 תאמת שאת השאלה הזו לא ממש ראיתי לפני שבניתי את הפרויקט ובסופו של דבר הפרויקט בנוי לכמות פריטים גדולה כי עשיתי סינון ראשוני ממש משמעותי מלא פונקציות שמתחברות לפונקציה אחת גדולה כך 
 של: AI מגיע ממש כמות קטנה של פריטים כך שזה חוסך בעלות ובזמן.
